Approved design: realtime layout resource estimates (18 October 2026)
GPU workload uses source render pixels per second plus full output pixels times
the highest active virtual refresh target. Reference: native panel at its detected
refresh, using the same formula. This is a relative workload index, not hardware
utilization, an FPS guarantee, or a capacity/safety threshold.
Memory model: two BGRA buffers per virtual source and two physical output buffers.
Report MiB and a bar relative to the same native reference. This estimates screen
buffer storage, usually VRAM; app RAM, game assets and driver/DWM allocations are
excluded. Refresh alone does not change this memory model.
All valid layout options flow through LayoutEngine; only calculated pixels and
Hz influence demand. Names/inches/primary/order alone have no resource cost.
Valid numeric drafts update estimates while typing, without saving or applying.
Invalid drafts clear estimates rather than leaving stale values.

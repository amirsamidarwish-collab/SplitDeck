SplitDeck v0.1.10 EXPERIMENTAL — cursor fix and interaction testing
18 October 2026

CONFIRMED CURSOR FAULT AND FIX
On this machine the first GetCursorInfo call succeeds and clears CURSORINFO.cbSize.
The presenter initialized cbSize only once. Subsequent queries failed with
ERROR_INVALID_PARAMETER (87), so the cursor was drawn only once and disappeared.
This was reproduced on the unchanged physical desktop without the virtual driver.
The native wrapper now initializes cbSize immediately before EVERY query.
A separate GDI buffer-canary test found no cursor bitmap header overrun.
Microsoft API contract: initialize cbSize before calling GetCursorInfo:
https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getcursorinfo
